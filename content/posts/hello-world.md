## Hugo 是什么？

Hugo 是用 Go 编写的静态网站生成器。它把 Markdown 文件 + 模板 + 主题编译成纯静态的 HTML/CSS/JS，部署到任何静态托管服务（GitHub Pages、Netlify、Vercel、Cloudflare Pages…）都能跑。

## 为什么选 Hugo？

- 一次构建、永久存在，访问速度极快
- 没有任何数据库、不需要运行任何服务器进程
- 写文章就是写 Markdown，可以纯用 Git 管理
- 主题生态丰富，可以零代码切换外观
