## 关于本站

这是一个用 [Hugo](https://gohugo.io/) 搭建、由 [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 主题渲染、并通过 GitHub Actions 自动部署到 GitHub Pages 的静态博客。

源代码托管在 [ernsky/ernsky.github.io](https://github.com/ernsky/ernsky.github.io)。

## 写第一篇文章

```bash
hugo new posts/my-first-post.md
```

把文件里的 `draft: true` 改成 `draft: false`，然后 push 即可上线。
